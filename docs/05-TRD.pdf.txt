and three domain-specialized Next.js frontend portals.

4. Authentication, Session Security & ADR-001 Isolation
4.1 Better-Auth Architecture
HireX uses Better-Auth cryptographic primitives for user authentication. Sessions are tracked via HTTP-only
cookie better-auth.session_token .
4.2 Portal Session Isolation (ADR-001)
To prevent cross-portal session contamination between Candidate, Recruiter, and Interviewer roles:
1. Extraction: The backend session-cookie.ts  utility extracts the cookie carrier.
--- Page 6 ---
2. Context Resolution: The user record is fetched from PostgreSQL. The backend checks user.role :
RECRUITER : Permitted to access /recruiters/* , /jobs/* , /reports/* .
INTERVIEWER : Permitted to access /interviewer/* , /interviews/* .
CANDIDATE : Permitted to access /candidate/* , /applications/* .
3. Role Guards: If a Candidate session attempts to query Recruiter endpoints, the request is rejected with
403 Forbidden  and the user is redirected to the respective login screen.

6. Schedular (MeetX) Video Integration & Webhook Lifecycle
6.1 Provider Pattern ( MeetingProvider )
export interface MeetingProvider {
  createMeeting(options: MeetingOptions): Promise<MeetingResult>;
  getTranscript?(meetingId: string): Promise<any>;
  getMom?(meetingId: string): Promise<any>;
}
Fallback Dev Simulation: When SCHEDULAR_API_KEY  is empty, returns
https://meet.hirex.dev/join/${meetingId}  for safe offline testing.
Live Video Calling: When configured, dispatches POST
https://api.dev.scheduler.zobay.in/api/v1/meetings . It saves hostJoinUrl  (privileged host
controls) and candidateJoinUrl  (attendee link).
6.2 HMAC-Signed Webhook Ingestion
Inbound webhooks sent to POST /webhooks/schedular  must supply header x-signature .
The backend verifies HMAC SHA-256 against process.env.SCHEDULAR_WEBHOOK_SECRET .
On meeting.ended , the interview status transitions to COMPLETED .
On meeting.mom.ready , the system calls getMom()  and getTranscript()  to attach minutes of
meeting to the interview record.
7. Cloudflare R2 Storage & File Management
Storage Provider: Cloudflare R2 bucket ( hirex-test-dev ) configured via AWS S3 SDK.
Signed URLs: Documents and resumes generate secure presigned URLs for in-browser PDF
previews.
--- Page 9 ---
Cascade Safety: Prisma schema enforces onDelete: SetNull  on Application.resume  so
candidate deletion does not trigger unhandled foreign key crashes.
8. Scheduled Background Tasks
HireX implements @nestjs/schedule  for asynchronous jobs:
Offer Expiration Cron ( @Cron('0 * * * *') ): Runs every hour at minute 0.
Queries all Offer  rows where status == EXTENDED  and expiresAt < NOW() .
Atomically updates them to EXPIRED .
Updates application status to notify recruiter of stale offer.
