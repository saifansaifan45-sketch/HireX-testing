1. Prerequisites & System Requirements
Before starting local development, ensure the following are installed:
Node.js: v20.x  or higher (LTS recommended)
Package Manager: npm  (v10+)
Database: PostgreSQL 15+ running locally on port 5432
Operating System: Windows, macOS, or Linux
2. Step-by-Step Local Environment Setup
2.1 Backend API Setup ( hirex-Backend )
cd hirex-Backend
# 1. Install dependencies
npm install
# 2. Configure environment variables
# Copy .env.example to .env
cp .env.example .env
# 3. Apply database migrations
npx prisma migrate deploy
# 4. Seed initial multi-tenant test data
npx prisma db seed
# 5. Start the backend development server (Port: 3001)
npm run start:dev

5. Troubleshooting Common Failure Modes
5.1 "ECONNREFUSED 127.0.0.1:5432"
Cause: PostgreSQL service is not running locally.
Fix: Start PostgreSQL service via your OS service manager (e.g. services.msc  on Windows or brew
services start postgresql  on macOS). Verify credentials in DATABASE_URL .
5.2 "Prisma Schema Drift / Migration Warnings"
Rule: NEVER run npx prisma migrate reset  in an environment where you want to keep test data.
Fix: Always run npx prisma migrate deploy  to apply pending migrations incrementally.
5.3 Cookie Not Being Saved / Login Redirect Loop
Cause: COOKIE_DOMAIN  environment variable is set incorrectly.
Fix: For local development ( localhost ), ensure COOKIE_DOMAIN  is commented out or empty in
hirex-Backend/.env . Leading dot domains (e.g. .hire.zobay.in ) only work in deployed multi-
subdomain environments.
5.4 Schedular / MeetX Video Links Show
https://meet.hirex.dev/join/mtg_...
Cause: SCHEDULAR_API_KEY  is not set in .env .
Status: This is the intended mock development fallback. If you wish to generate live Schedular video
links, obtain a dev API key from the platform team and populate SCHEDULAR_API_KEY .

5.5 Port Conflicts (EADDRINUSE: 3000 / 3001 / 3002 / 3003)
Fix: Check running Node processes ( Get-Process node  on Windows PowerShell or killall node
on macOS/Linux) and terminate lingering development servers.
